# ExampleProject — Canned Report Image Viewer

Minimal **Python Shiny** app for displaying canned report screenshots.

## Setup

```bash
pip install shiny
```

## Run

```bash
cd ExampleProject
shiny run app.py
```

## Canned images

Place PNG/JPG/GIF/WebP files in `report_images/`. Use **Refresh list** in the sidebar after adding files.

A text placeholder is included so the folder exists in git.

## Purpose

Demo target for PrizmForge unattended / test_mode runs: agents materialize this app under `project_directory`.
